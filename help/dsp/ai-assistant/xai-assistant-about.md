# Über den KI-Assistenten in Advertising DSP

Der KI-Assistent in DSP ist eine Dialogschnittstelle, mit der Sie jeden in DSP verfügbaren agenten Workflow über einen einzigen Chatbox durchführen können. Sie können eine neue Aufgabe erstellen oder um Hilfe bei der Fortführung einer vorherigen Aufgabe bitten.

Der Verlauf einer Konversation wird für alle Workflows beibehalten, wobei jede Konversation automatisch benannt wird. Ihre Abfragen werden nicht für andere Benutzer freigegeben.

## Best Practices für das Schreiben von Abfragen und Eingabeaufforderungen {#writing-queries}

* **Seien Sie klar und präzise**. Verwenden Sie vollständige Fragen („Wie abonniere ich ein On-Demand-Inventar?„), Aufgabensätze („Abonnieren eines On-Demand-Inventars„) oder Themensätze („On-Demand-Inventar„).

* **Kombinieren Sie nicht verschiedene Arten von Anfragen in derselben Abfrage** es sei denn, Sie möchten, dass sie in derselben Konversation gespeichert werden.

* **Schließen Sie ggf. Datumsbereiche ein** um die gewünschten Daten einzugrenzen.

* **Benutzeroberflächenbegriffe abgleichen** wenn möglich für Produktfunktionen (wie „Kampagnen“ oder „Angebote„).

  Für häufige Aktionen (z. B. „Hinzufügen“, „Anhängen“ oder „Zuweisen„) können Sie Synonyme verwenden.

* **Detail hinzufügen** um die Ergebnisse einzugrenzen oder zu erweitern. Verfeinern Sie dies mit Folgefragen nach Bedarf.

* **Machen Sie sich keine Gedanken über Interpunktion und**, außer wenn sie die Bedeutung beeinflussen.
